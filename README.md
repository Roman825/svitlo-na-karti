# Світло на карті

Карта актуальних графіків відключень електроенергії. Публічна частина курсового проєкту
«Smart Grid SCADA» (система моделювання, моніторингу та управління енергомережею).

- Графіки груп підтягуються наживо з відкритих даних операторів.
- Будинки на карті пофарбовані за своєю групою відключень.
- Блок «Стан енергосистеми» публікує диспетчер із застосунку.

Відкриті дані сайту лежать у теці `api/` (опис — у `api/index.json`).
